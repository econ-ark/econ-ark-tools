# texmf-local: LaTeX support files shared across Econ-ARK projects

The econark class and packages, the BibTeX styles and the build scripts that each
project's `@resources/` copy carries. econ-ark-tools is their single source of truth.

Chris Carroll's own TeX tree, with the econtex and handout classes and the shared
bibliography `economics.bib`, is the public repo
[llorracc/texmf-local](https://github.com/llorracc/texmf-local).
